# BISU Clarin — Secure Smart Campus Navigation & Monitoring System
**College of Science and Management — Final Project with Discrete Mathematics & Foundation Prototype**

---

## 1. How to Run the Web Application (v2 Full System)
1. Double-click **`index.html`** to open it directly in any modern web browser (Chrome, Edge, Firefox, Brave, or Safari), **OR** open the folder in VS Code and launch it with **Live Server**.
2. Navigate the 7 interactive tabs at the top:
   - **0. V1 Foundation (Access & Number Theory)**: Original Student Access Management System prototype (Honielyn A. Torres and Jheanne Mae M. Cabudlan) featuring interactive user access verification, dynamic access relation matrix highlighting, and step-by-step Euclidean algorithm \(\gcd(a, b)\) tableau.
   - **1. Finite State Machine (FSM)**: 7-state security controller with strictly guarded transition function \(\delta(q, \sigma)\).
   - **2. Cryptography & Auth Gate**: Vigenère, Caesar, XOR hex stream cipher, and SHA-256 salted credentials.
   - **3. Graph Navigation & Recursion**: Weighted campus network, Dijkstra shortest path, and recursive DFS.
   - **4. Campus Tree & Recursion**: Hierarchical directory with Pre-Order/Post-Order traversals and recursive capacity calculations.
   - **5. Searching & Sorting**: Recursive Merge Sort, Quick Sort, Insertion Sort, Binary Search \(O(\log n)\), and Linear Search.
   - **6. Probability & Random Variables**: Permutations \(P(n, r)\), Combinations \(C(n, r)\), PMF, \(E[X]\), \(\text{Var}(X)\), and Monte Carlo room occupancy simulation.

---

## 2. How to Run the Python Prototype CLI (v1 Console)
The foundational console application by Honielyn A. Torres and Jheanne Mae M. Cabudlan is included as a standalone script:
```powershell
python v1_prototype.py
```
This lets you run the terminal-based interactive menu to check user access, view the access matrix, and execute number theory calculations (Even/Odd, Modulo 5, and Euclidean GCD).
