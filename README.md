# BISU Clarin — Secure Smart Campus Navigation & Monitoring System

## How to Run the Web Application
1. Extract `bisu-smart-campus.zip` to any folder on your computer.
2. Double-click **`index.html`** to open it directly in any modern web browser (Chrome, Edge, Firefox, Brave, or Safari), **OR** open the `bisu-smart-campus` folder in VS Code and launch it with **Live Server**.
3. Use the 6 interactive tabs at the top to demonstrate every required syllabus feature.
